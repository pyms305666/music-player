# 歌单导入：4.2.0 / Windows 4.2.2 修复

入口：Windows 顶栏“我的歌单”（也在“导入音乐”菜单中）；Android 本地歌单页“我的歌单 / 导入歌单”。

## 使用流程

1. 粘贴酷狗、网易云或 QQ 音乐的公开歌单分享文字 / 链接。程序只读取公开内容；私密、删除或需要登录的歌单会报告错误。
2. 核对歌单封面、作者、名称、读取数量和歌曲顺序，选择全部或部分曲目。平台数量缺失或读取数量不一致时显示提示，允许核对后保存已经读取的内容。
3. 指定下载目录及是否检查子目录。“导入后下载选中的歌曲”默认关闭，关闭时只保存歌单和本地关联。
4. 若发现重复歌曲，集中选择“使用本地”或“仍然下载，保留两份”。相同来源的歌曲标识属于确认重复；歌名和歌手一致属于疑似重复，保留 Live、翻唱、混音等版本信息供用户判断。未知歌手不自动匹配。
5. 导入完成后，可以下载选中 / 未完成项，暂停继续，取消，搜索、重命名、调整顺序、更改目录，或播放本地歌曲 / 加入播放队列。需要人工核对版本时，只勾选一首歌曲并点击“选择下载版本”，查看本软件的各渠道搜索结果后确认。重新导入同一平台歌单时可以更新已有歌单或另存一份。更新采用本次选择的清单及平台顺序，不删除音频。

Android 首次检查默认目录的重复曲目会申请读取音乐权限；拒绝后可改为选择系统授权的其他目录。默认目录为共享存储 `Music/music/`，Android 9 使用应用外部音乐目录。系统目录选择器授予的访问权限会持久保存，权限失效时会明确报错。

## 数据和下载行为

- 歌单与曲库、音频和当前播放队列独立；删除歌单只删除歌单记录。
- 分别保存原歌单歌曲标识和实际下载渠道 / 歌曲标识，保留顺序、版本名称、时长、封面、本地位置和下载状态。桌面增表，Android schema 3 → 4 增表，保留原曲库、歌词及导入映射。
- 下载最多同时处理 2 首，逐首持久化结果；大歌单不会一次挤入原下载队列。歌单内重复行保留，但相同歌曲可共用一个新文件；明确选择保留两份时分别生成文件。
- 新文件采用唯一文件名，保留已有文件。下载失败保留元数据及错误，可单独重试。取消保留已完成文件；暂停停止领取新任务，正在下载的歌曲正常完成。
- 离开页面后下载继续。应用进程结束后不会自动启动下载；再次打开将中断项标记为可继续下载，用户通过“下载未完成”恢复。
- 完成下载仅刷新本地曲库，不自动切歌。播放歌单按照本地可用曲目的歌单顺序播放，保留重复行。
- 歌单来源与下载渠道分开：歌单来自酷狗、网易云或 QQ；音频通过本软件已有的酷我、咪咕、QQ、网易云、酷狗渠道下载，优先酷我、咪咕。自动匹配要求歌名、歌手和版本一致；同源同歌曲标识也可直接使用。一条渠道失败后依次尝试其他符合要求的结果，显示实际下载渠道。无法匹配时可人工选择版本，人工确认的选择不会静默替换。某些歌曲可能始终不可下载，会保留失败项，不保证每首都能获得音频。
- 人工选择后独立保存确认标记，失败、取消、重新打开应用和“下载未完成”重试均保留该版本及渠道；自动下载的失败项仍可重新匹配已有渠道。重新点击“选择下载版本”可以改变选择。人工选择其他版本后保留原歌单信息，并显示已选版本；重复检查以选定版本为准，复用本地文件也保留选择，不会把其他版本的文件作为原歌曲的确认重复证据。

## 适配方式和边界

三家平台共用链接解析和结果模型，分别适配公开响应。短链接最多跟随 6 次平台内跳转，不执行网页中的脚本。

- 网易云：公开 `playlist/detail` 的歌曲 ID 顺序，缺失详情按 200 首批量补齐；未返回详情的 ID 保留占位项。
- QQ：公开歌单详情分页，每页 100 首，检测平台重复返回同一页；保留歌曲原顺序，数量不一致提示用户。
- 酷狗：当前公开分享页嵌入的 JSON。旧的移动 speciallist 地址已在实测中跳转首页；移动 `gcid_` 分享需要保留 `src_cid`，使用移动 User-Agent 读取。没有总数或公开页返回不完整时提示用户核对。
- 单个歌单上限 20000 首。不支持账号登录、私密歌单、自动同步远端修改、歌词文件批量导出或字节级断点续传。
- 目录匹配依赖已保存关联和音频的歌曲信息 / 常见“歌手 - 歌名”文件名，无法从未知文件名可靠推断歌曲。疑似重复由用户确认。

## Windows 4.2.2 批量下载修复

2026-10-09 用户歌单为 9 首，本地记录显示 3 首可用、6 首失败，失败项均为自动匹配。批量下载已有渠道回退，但标题全等规则误排除了跨平台标注不同的同一录音：酷我为《爱最闪耀》增加原唱 cover 标注，将三个 Live 版本的现场信息放在专辑名中。现在仅在歌手集合相同、明确专辑相同的条件下协调这些标注；3D、Remix、具体活动名称仍保留。已知现场专辑的 Live 歌曲也不自动匹配其他演出或专辑信息缺失的同名 Live 结果。

下载器本身在每次自动重试时清除上一次缓存的失败渠道，重新搜索并按酷我、咪咕等顺序尝试同版候选；人工固定的版本和渠道仍保留。失败详情记录各渠道是否搜索完成、超时或失败、同版候选数量以及实际尝试的全部渠道；列表和详情提示按窗口宽度换行。

使用只读的用户元数据副本及内存歌单存储，在独立测试目录运行真实批量下载器，9 首中 7 首下载成功，全部使用酷我；7 个文件共 64098158 字节，文件头为 ID3 或 MPEG 音频，JavaFX 媒体解析全部进入 READY。新增成功为《爱最闪耀》、毛不易单人版及毛不易 / 徐航合唱版《像我这样的人 (Live)》、《平凡之路 (Live)》，四首实际音频时长与歌单时长差异均小于 50 毫秒。测试未写用户数据库和原下载目录。

本次《消愁 (2018王者荣耀三周年音乐盛典现场)》及《海阔天空 (3D环绕版)》的五个渠道搜索均完成，但只有酷狗原版本候选，且未提供可用下载地址。保留失败项，用户可通过“选择下载版本”自行确认其他录音；自动下载不会把它们替换为普通录音室版。本次可用性是当日实测结果，后续接口响应可能变化。

本轮新增回归覆盖同专辑 cover 标注、现场标注迁移、不同演出 / 3D / Remix / 歌手不一致拒绝、下载引擎直接重试清除自动缓存渠道，以及持久保存各渠道搜索结果与尝试记录。共享模块 Java 25 / Java 17 各 117 项通过；桌面 43 项通过、1 项既有性能基准跳过；桌面歌单及 15 个操作的实际鼠标烟测通过，Android Debug 构建及 lint 通过（0 Error / 33 既有 Warning）。Debug APK 仅用于编译检查，未作为本轮分发包。
