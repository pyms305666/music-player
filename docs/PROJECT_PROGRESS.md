# 项目进度

## 2026-11-01：歌手搜索与歌曲下载优化

状态：源码修改、自动验证、联网实测和本地构建已完成。针对用户搜索“黄霄云”结果不全的问题，增加可见结果，并优先验证酷我、咪咕的实际下载。

### 已完成

- 酷狗和酷我每次请求及解析的上限从 10 首提高到 50 首，网易云从 8 首提高到 50 首；结构化解析和已有正则后备同步调整。
- 咪咕接口每页最多返回 20 首，播放器最多读取前三页并按 contentId 去重。后续页报错时保留已取得的歌曲；第一页报错仍报告来源失败；取消会中止请求。
- 网易云实际响应可能在歌曲 ID、名称之前放置嵌套专辑和歌手信息。旧解析会误读嵌套 ID（例如 0），接着用后备规则生成“未知歌手”；现在按 JSON 对象层级读取歌曲、歌手及专辑。
- 用户主动选择的歌曲仍先尝试其原来源。需要换源时，先筛选全部匹配候选，再按酷我、咪咕、其他来源排序，最后保留最多 6 个候选，避免候选尚未排序就被截断。
- 版本更新为 4.2.5（Android versionCode 40205），同时更新 README、项目说明和全量附录。

### 发布验证中的 Windows 路径修复

首次远端 Windows CI 使用 `RUNNER~1` 短路径，迁移测试发现曲库中已有文件可能以短路径或目录链接引用同一真实音频。数据库迁移现在匹配实际源文件，并在目标已有别名记录时复用该记录，避免重复曲库或留下失效的歌曲及歌单引用；已新增源和目标目录链接回归。测试临时目录先解析真实路径，子进程参数使用 Base64 包装 UTF-8，避免英文 Windows 代码页损坏中文路径和阶段名。修复后的桌面及共享回归、六个迁移界面场景和实际 Windows 短路径临时目录中的迁移测试已通过；Android 正式签名隔离探针通过。最终重建、CI 及发布状态以对应提交的 GitHub 运行记录和 Release 为准。
