本次更新完成双端"幽蓝深空流光感"视觉重构，并补齐方案验收差距：封面驱动的环境流光、高精度音质徽章与歌词沉浸样式。

- 双端统一深空配色与磨砂浮岛视觉：深空石墨基底、幽蓝/冰青强调色、胶囊音质徽章体系；Android 播放面板与底部导航呈半透明浮岛质感。
- 环境流光随封面变化：桌面端内容区径向流光与封面阴影光晕由封面主色驱动（采样平均色并按饱和度/明度安全钳制）；Android 端封面背后光环同步取色，加载失败或灰白封面回退默认幽蓝。
- 桌面播放条新增高精度音质徽章：按文件头识别 FLAC、WAV、APE 与 MP3 实际码率（如 320K），不依赖文件扩展名；曲库列表行保留轻量扩展名徽章。
- 修复桌面歌词工具栏悬浮按钮遮挡滚动歌词的问题：工具栏改为独占一行置于歌词区上方。
- 歌词焦点样式双端统一：正在播放行纯白加粗（桌面附外发光），非焦点行褪光；Android 无时间戳歌词保持纯白可读。
- Android 歌词页升级为悬浮磨砂歌词岛，封面为大圆角并带光环背景；小屏设备按可用高度自适应封面尺寸。

本地验证包括桌面 107 项测试、共享模块测试、Android release 构建与 lint、正式签名检查（密钥轮换链与策略核对），并以真实窗口截图核对了流光可见性、工具栏布局、音质徽章与歌词样式。在线搜索结果暂无逐首音质标识：当前来源搜索接口不返回每首歌的码率字段，且本版本遵守不修改网络解析层的约束；Android 播放条徽章按扩展名判定。本版本未在隔离 Windows 系统重新验证安装升级，也未在 Android 设备重新验证在线下载。

Android 正式包沿用既有签名及证书轮换策略；Windows 安装包内含运行时。源码提交、CI、附件签名和 SHA-256 以 Release 中的 `build-info.json` 与 `SHA256SUMS.txt` 为准。
