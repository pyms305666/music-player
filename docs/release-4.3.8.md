本次更新把双端背景光效升级为 Apple Music 式大面积流体流光，并修复封面显示与亮度问题。

- 流体流光：背景铺设多个大尺寸软边色团，颜色取自封面整体与四象限区域的色板；各色团以互错周期独立漂移与呼吸，叠出非重复的流动感。桌面端色团渲染统一提升饱和度与亮度，只保留封面色相，避免平均色在深底上发灰。
- 封面显示修复：播放就绪即显示音频内嵌封面，不必等待歌词查询；歌词查询未返回封面时不再清空已显示的封面。
- 封面亮度：桌面端封面轻度提亮；Android 端流体色团在 API 31+ 使用 RenderEffect 实时模糊，低版本回退软边渐变。
- 修复桌面端 CSS 中一组不受支持的自定义变量导致的样式解析错误。
- 携带 4.3.7 的全部修复：桌面歌词工具栏不再遮挡歌词、播放条文件头级音质徽章、歌词焦点样式双端统一。

本地验证包括桌面 107 项测试、共享模块测试、Android release 构建与 lint、正式签名检查，并以真实窗口像素取样验证了播放全程色团持续渲染、随封面变色与漂移动画。在线搜索结果仍无逐首音质标识（来源接口不提供且不修改网络解析层）；Android 播放条徽章按扩展名判定。本版本未在隔离 Windows 系统重新验证安装升级，也未在 Android 设备重新验证在线下载。

Android 正式包沿用既有签名及证书轮换策略；Windows 安装包内含运行时。源码提交、CI、附件签名和 SHA-256 以 Release 中的 `build-info.json` 与 `SHA256SUMS.txt` 为准。
