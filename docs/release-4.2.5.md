本次更新改善歌曲搜索和下载，并加入 Windows 安装位置、音乐保存位置及旧歌曲迁移功能。

- 搜索歌手时，酷狗、酷我和网易云每次最多返回 50 条；咪咕最多读取三页，每页 20 条。修复网易云歌曲和专辑嵌套字段被混淆的问题，改善歌手及歌曲名称显示。
- 下载先尝试所选来源；需要换源时优先尝试匹配的酷我、咪咕歌曲，再尝试其他来源。歌曲版本和来源可用性仍会影响实际下载结果。
- Windows 安装向导支持选择安装目录。首次下载可选择音乐文件夹，之后可以在主界面的“下载位置”修改；安装位置与音乐位置分别设置。
- 修改音乐目录时，可选择仅影响后续下载，或在重新启动后迁移旧音频及配套歌词，同时更新曲库和歌单路径。复制校验和数据库更新成功后才逐项清理旧文件；遇到占用、文件变化或目标盘不可用时保留旧文件供处理。
- 增加项目结构说明、离线文件附录及代码注释，并整理歌词、曲库和下载相关组件。

本地验证包括桌面测试、Java 17 与 Java 25 共享测试、Android 构建和 lint，以及桌面播放、歌单和目录迁移界面检查。实际联网测试中，酷我成功下载《星辰大海》，咪咕成功下载《烟火里的尘埃》；具体日期、范围及限制见 `docs/PROJECT_PROGRESS.md`。本版本没有在隔离 Windows 系统中重新验证安装、升级和卸载，也没有在 Android 设备上重新验证在线下载。

Android 正式包沿用既有签名及证书轮换策略；Windows 安装包内含运行时。源码提交、CI、附件签名和 SHA-256 以 Release 中的 `build-info.json` 与 `SHA256SUMS.txt` 为准。
