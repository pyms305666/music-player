# 第二轮性能与验证记录（4.1.11）

## 环境与测量方法

- 同一 Windows 机器、JDK 25.0.2，独立 JVM 参数 `-Xms64m -Xmx256m`；共享模块另以 Java 17 验证。
- 基线为 4.1.10（`ec1c841`），优化前数据在修改在线搜索实现前采集。
- `scripts/OnlineSearchBenchmark.java` 使用两个可控来源，分别延迟 25ms 和 200ms；预热后每批查询 5 次，共 3 批。不访问第三方网站或个人数据库。
- `legacy` 记录整批返回；`incremental` 记录后端首个非空快照与最终完成；`cached` 预先缓存正常完成查询，记录缓存结果返回。
- 峰值是 JVM 堆内存池峰值之和；稳定堆在相同 GC 流程后采样。不是操作系统进程工作集或 Android PSS。

首批结果更早交付，总耗时基本持平；增量状态及传输依赖带来约 9% 的稳定堆增加（分别约 9.7%、9.1%、9.0%）。没有目标指标连续三批退步超过 10%。缓存数据仅证明可控查询命中成本，不能推断真实网络提速倍数。HTTP 客户端延迟创建；此处可控来源不打开连接，因此这些堆数据不代表实际网络连接池或整机内存。

UI 最多每 100ms 刷新一次；后端首批结果耗时不等于用户看到结果的时间。已通过 JavaFX 实际控件验证快来源结果在慢来源释放前出现，追加结果和最终状态均保持选择。结果不再为来源优先级重排，跨来源下载回退仍沿用原优先级。

## 资源与行为边界

- 查询缓存最多 50 项/2 分钟，主动清理过期项；正常无结果可以缓存，异常、超时、来源暂停、用户取消均不缓存。
- 关键词规范化直接按 Unicode code point 合并空白并按 Locale.ROOT 转小写，支持 NBSP、全宽空格、NEL、中文和补充平面字符。真机及模拟器曾暴露 Java 正则 `(?U)` 在 Android ICU 中抛 PatternSyntaxException；已移除该平台专属标志，增加 JVM 与真实 Android 控件输入回归。
- 来源解析区分合法空数组与 HTTP 200 的错误页、业务错误码、缺失结果字段；网易云明确返回 songCount=0 时允许省略数组。异常响应不会污染“没有歌曲”的缓存。
- 搜索使用原有 10 秒总预算，来源池 5 个线程；搜索协调、预览、下载分别拥有执行器和取消令牌。
- CI 暴露 Linux 下 `HttpURLConnection.disconnect()` 等待阻塞读取的问题。共享 HTTP 改为固定版本 OkHttp 4.12.0 的同步调用，仅替换会话内部传输；单请求绑定 `Call.cancel()`，保留 CookieManager、POST、请求头和响应契约。重定向逐跳按域读取/保存 Cookie；绝对搜索截止时间覆盖响应体，下载 180 秒仍为读取空闲超时。依据：[Square 4.12.0 实现](https://raw.githubusercontent.com/square/okhttp/parent-4.12.0/okhttp/src/main/kotlin/okhttp3/internal/connection/RealCall.kt)。
- 下载队列锁内只更新取消状态，连接和 Future 取消在锁外执行；最后消费者取消时立即标记该任务，防止锁外交接中迟到的文件被发布。咪咕探活也复用同一可取消会话。
- 关闭调度器或 UI 后，进度组件丢弃已失效的通知，不让调度拒绝阻断任务 Future、取消令牌和资源收尾。
- 下载 2 项运行、8 项等待，拒绝第 11 个不同任务；相同歌曲及规范化目录共享传输。取消一个订阅不打断其他消费者或其他歌曲。
- 下载进度包含阶段、已传输字节、可选总大小。Java HTTP 使用 Content-Length；curl 未提供可靠总大小时仅报告已写入字节。
- 完成下载后的加入曲库阶段不可中途取消，避免留下半写数据库；在现有控件提示等待。
- `.part` 清理由对应下载任务负责；Android 发布后清理其私有暂存文件，桌面有效歌曲保存在原下载目录。
- 下载完成到入库之间的交接在 UI 线程与页面关闭串行；页面已关闭或发布调度遭拒时，Android 归还并清理尚未发布的暂存文件，避免 executor 关闭竞态。
- 两个主界面将在线状态接入提取到专属 UI 组件，共享控制器负责传输与发布交接，未扩大主界面职责。
- 复核发现失败 Future 的便捷方法只在 Android API 31 起提供，已改用构造 Future 并 completeExceptionally，保持 API 28 安装范围。依据：[Android CompletableFuture API](https://developer.android.com/reference/java/util/concurrent/CompletableFuture#failedFuture(java.lang.Throwable))；不能仅以 Java 17 编译成功判断安卓兼容性。

## 验证及发布门禁

源码提交前已完成桌面 34 项、共享 Java 17/25 各 82 项测试（全部无失败、无跳过），Android 构建和 lint（0 错误、26 警告）、JavaFX 实际控件烟测。新增覆盖快慢来源、部分/全部失败、到达顺序、不可变快照、正常空查询、缓存过期/LRU、旧回调、取消隔离、下载队列满、共享下载、发布去重、取消后清理和重试。原 Linux 取消失败用例及其超时保持原样，新增真实 HTTP 的头部/响应体取消、会话关闭、截止时间、提前取消、Cookie/POST/跨域跳转和占满两个下载线程后的取消释放/隔离/临时文件清理，以及调度器/UI 已关闭的进度收尾。最终三批优化后数据在传输、关闭竞态及 Android 关键词兼容修复后重新采集。

Android 离线控件测试使用真实 `activity_main` 主题布局及私有临时目录，覆盖追加选择、下载大小、取消/重试和缓存，不启动 Activity 或打开个人数据库。CI 的 ActivityScenario 启动检查曾发现控制器将实际 ImageButton 当作 Button 的转型崩溃；已将接口改为正确的 ImageButton，并用搜索/关闭/刷新图标、无障碍描述及 tooltip 展示动作，保留现有布局。测试从手工创建 Button 改为真实 XML 控件，防止此边界漏检。修改后编译和 lint 已通过；真实布局用例和 Activity 启动仍须在新提交模拟器及真机执行，编译通过不代表设备用例已通过。

API 28/31/32/33 签名升级矩阵也运行在线列表、控件及真实 loopback HTTP 用例；后者通过 ServerSocket 验证 Android 实际初始化传输、响应体取消释放同一工作线程、后续请求及 Cookie，关闭所有 socket 和执行器，不访问公网或个人数据。新增发布调度拒绝时清理暂存文件、展示失败并提供重试的设备测试，以覆盖最低版本的异常路径。保留该脚本对真机禁止清空安装和播种测试曲库的限制。

严格维护性自审与 `check-work` 在传输源码及本地验证范围通过。CI 发现跨平台取消阻塞后，独立复核又发现取消与关闭调度器并发时的收尾竞态；两项均已修复，独立重新运行两套构建、测试和烟测通过。原关闭竞态复现确认 cancelReturned=true、tokenCancelled=true、resultDone=true；独立探活检查还确认 Range、取消、503 拒绝、后续会话可用及 activeCalls 释放。随后模拟器 CI 暴露上述控件类型问题；已修复并重新本地构建，独立核对其余 XML 接口类型未发现同类问题，但此发现说明此前局部 PASS 不能替代真实设备门禁。对应新提交全部 CI 仍须通过。此前修复包括未发布暂存文件的关闭/拒绝竞态、HTTP 200 异常及截断响应误缓存、空查询未通知结束，以及低版本安卓失败 Future API 的问题。独立复核以手动调度器/可控时钟验证 2,000 次更新只保留一个任务、100ms 节流和关闭回调失效；不使用性能计时作为 CI 成败断言。

本文记录提交时的实现与测量。真机已连接，首次回归中播放、列表、覆盖升级数据保留通过，但在线关键词的 Android 正则兼容失败，已修复；最终源码的全部 12 项功能测试必须重新通过。独立复核、对应提交全部 CI、最终两端附件的干净源码/散列/签名核对，以及真机循环、后台/锁屏、个人曲库实际播放、覆盖升级后数据保留，均为公开 Release 前必需门禁。最终结果以对应 Release 的 `build-info.json` 和 Actions 为准，不将首次回归或编译成功替代最终设备门禁。

## 剩余限制

第三方来源的长期可用性、网络吞吐和多机型长时间耗电未由离线测试证明。查询缓存按项数限制，保留两分钟内的完整结果；下载地址及桌面磁盘缓存的容量约束、歌词定位和 Android 批量导入留到第三轮。
