新增 Windows / Android 歌单导入，并修复导入交互和批量下载的匹配、重试与并发问题。

- 支持粘贴酷狗音乐、网易云音乐、QQ 音乐的公开歌单链接或分享文字，预览歌曲后选择导入。歌单独立保存，可仅导入清单，也可同时下载。
- 下载使用 ZA音乐已有渠道，优先酷我、咪咕；同版候选失败后尝试其他渠道，分别保留歌单来源和实际下载来源。支持手动选择下载版本。
- 可设置下载目录及检查子目录；发现本地重复歌曲时集中询问，支持复用本地文件或保留两份，避免覆盖已有音频。
- 提供歌单搜索、重命名、排序、删除、播放本地歌曲和加入播放队列。批量下载最多同时处理两首，支持暂停、继续、取消和重试未完成曲目；离开歌单页面后任务继续，下载完成不自动播放。
- 修复桌面导入弹窗“确认 / 取消”点击无反应，补齐 15 个操作的适用状态和反馈，统一深色背景、亮色正文及蓝色主要操作。
- 修复跨平台同一录音的 cover / Live 标注差异导致误排除、自动重试沿用旧失败渠道，以及两个歌曲任务争用搜索线程的问题。人工指定的版本仍保持固定。
- 酷我搜索优先读取完整歌名，保留 Remix、3D、DJ 等版本标注，避免将不同录音误当成原版；失败详情显示各渠道的搜索结果、候选数和实际尝试记录。

沿用安装身份、用户数据目录和 Android 正式签名轮换：Android 9 / API 28 起可安装，API 28–32 使用原证书，API 33 及以上使用轮换后的正式证书。曲库和歌词保留，删除歌单仅删除清单，不删除音频。Windows 安装包包含运行时，无需另外安装 Java。

本轮验证：桌面 15 个操作及真实链接导入、随包运行检查通过；共享逻辑在 Java 25 / Java 17 各 120 项通过。vivo V1962A / Android 10 真机首次安装及 12 项原生检查全部通过，无跳过。用户测试歌单 9 首全部导入，两端各成功下载 7 首，音频解析与时长核对通过；两首指定的 2018 现场 / 3D 版本没有可用同版地址，保留失败并允许手动选版。此前模拟器覆盖升级保留检查通过；本轮真机首次安装不作为旧版升级验证。

在线可用性取决于各平台当时响应；公开歌单可能不完整，私密或需要登录的歌单不支持直接导入。自动匹配保留录音版本，不保证每首歌曲都能下载。已下载的旧候选不会自动删除或替换，需要选中后重新下载并核对重复提示。

源码提交、成功 CI、安装包签名和 SHA-256 以本 Release 的 `build-info.json`、`SHA256SUMS.txt` 为准。仅提供 Windows EXE 和正式签名 Android APK；测试 APK 不作为分发附件。详细功能及验证范围见仓库 `docs/playlist-import.md`。
